# v1.9.0-dashboard

Director and ISP dashboards now each show ten role-specific summary cards in
two rows of five on desktop. The existing theme is retained. The dashboard
adds labelled hourly record statistics, role-appropriate health, actionable
device findings, NAT quality/coverage, searchable status tables and a compact
recent-record preview.

Previously enabled devices were labelled active and the health panel always
said ALL OK. This version separates enabled, online, silent and unknown device
states; resource and audit panels display actual API observations. All time
windows are explicit, including the process-lifetime decoded/skipped counters.

Refresh is bounded and component-specific. Pause/Resume, hidden-tab behavior,
partial failures, retained stale values and scoped Logs drill-down are covered
by isolated browser tests for both roles. Desktop sizes 1280/1440/1920 and
tablet/mobile sizes 900/390 are checked. CI validates the committed static
bundle and login flow; the Director view is also checked against live APIs.

This is a static UI release. The collector binary is unchanged and the release
is delivered through the existing Caddy/fetcher pipeline without restarting
natlog. Existing API limitations and the locked component contract are recorded
in [DASHBOARD-SCOPE.md](../DASHBOARD-SCOPE.md).
