# v1.10.1-isps

Module navigation now records the current page in its URL. Refresh restores that
page after authentication, and browser Back/Forward follows module navigation.
Unknown routes and pages unavailable to the signed-in role fall back to Dashboard.

ISP create/edit/delete forms now place an icon before each field label, a red
required star at the right edge of its label row, and a descriptive placeholder
or select prompt in every control. Optional edit passwords explain that leaving
them blank preserves the current password.

Validated with ISP and Logs refresh, Back/Forward, ISP role restrictions,
existing CRUD/validation tests, field layout checks and desktop/mobile review.
Delivered through the static UI pipeline without backend or collector restarts.
