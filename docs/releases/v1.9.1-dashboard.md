# v1.9.1-dashboard

The shared console header now shows a large page icon beside its title and
description, with role-aware breadcrumb navigation on the right. The breadcrumb
updates with the current page and returns to Dashboard when its home action is
selected. Narrow screens wrap the breadcrumb below the heading.

Small buttons, pagination, modal close buttons and status labels now follow the
square-corner theme, removing legacy radius overrides. Existing page tools sit
below the header so they do not displace the breadcrumb.

Validated with the Director/ISP browser suite, desktop and mobile screenshots,
asset/JavaScript checks, and an authenticated Director preview using live APIs
that checks header placement, square corners and breadcrumb navigation.
Delivery uses the static UI pipeline without restarting the collector.
